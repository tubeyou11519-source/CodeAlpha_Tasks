# Basic Chatbot

a basic chatbot that can respond to simple commands like greetings, asking it's name, the weather, telling jokes,etc using else if,elif and loops.

## Features
- Responds to greetings, name questions, jokes, weather, and thanks
- Matches keywords even inside longer sentences (e.g. "tell me a joke" still works)
- Runs in a loop until you type 'bye'

## How to Run:
```
python chatbot.py
```

## Concepts Used:
if-elif, functions, loops, input/output

## Example
D:\GitH\CodeAlpha_Chatbot>python chatbot.py
Simple Chatbot (type 'bye' to exit)

You: hi
Bot: Hi! How can I help you today?

You: whats the weather
Bot: I can't check the weather, but I hope it's nice outside!

You: tell a joke
Bot: Why do programmers prefer dark mode? Because light attracts bugs.

You: what can you do?
Bot: You can say hello, ask how I am, ask my name, or say bye.

You: thanks
Bot: You're welcome!

You: bye
Bot: Goodbye! Have a great day.
