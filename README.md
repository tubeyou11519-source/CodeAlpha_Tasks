# CodeAlpha_Tasks

This repository contains three Python projects developed as part of the CodeAlpha Internship Program. Each project demonstrates practical programming fundamentals through interactive command-line applications, covering game development, stock portfolio calculations, and basic chatbot functionality.

## Projects

### 1. CodeAlpha_HangmanGame
A text-based Hangman game where players attempt to guess a randomly selected word one letter at a time.

**Features:**
- Random word selection from a predefined word list.
- Tracks incorrect guesses, with a maximum of six allowed.
- Displays correctly guessed letters and the wrong-guess count
- Supports multiple rounds of gameplay.

Technologies used: Python, `random` module, strings, sets, loops, and conditional statements.


### 2. CodeAlpha_StockPortfolioTracker
A command-line stock portfolio tracker that calculates the total investment value based on user-entered stock symbols and quantities.

**Features:**
- Supports five predefined stock symbols: AAPL, TSLA, GOOGL, MSFT, and AMZN.
- Calculates the value of individual stock holdings and the overall portfolio.
- Displays a summary of the selected stocks and their quantities.
- Optionally saves the portfolio summary to a text file.

Technologies used: Python, dictionaries, user input/output, arithmetic operations, and file handling.


### 3. CodeAlpha_Chatbot
A simple, rule-based chatbot that interacts with users through predefined responses to common messages and keywords.

**Features:**
- Responds to greetings and questions about its identity.
- Handles basic weather-related queries, jokes, and expressions of gratitude.
- Recognizes keywords within longer user messages.
- Continues the conversation until the user enters `bye`.

Technologies used: Python, functions, loops, conditional statements, and string matching.


## Prerequisites
- Python 3 installed on your system.
- Git (optional, if you want to clone the repository).

No third-party Python packages are required for the documented projects.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/tubeyou11519-source/CodeAlpha_Tasks.git
cd CodeAlpha_Tasks
```

### 2. Run the Hangman Game

```bash
cd CodeAlpha_HangmanGame
python hangman.py
```

### 3. Run the Stock Portfolio Tracker

From the repository root, run:

```bash
cd CodeAlpha_StockPortfolioTracker
python tracker.py
```

### 4. Run the Chatbot

From the repository root, run:

```bash
cd CodeAlpha_Chatbot
python chatbot.py
```
